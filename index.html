Introduction

Here is a reproducible Quarto workflow where we used the linear model to predict levels of extraversion from demographic and personality variables.

Show code 
library(tidyverse)
library(psych)
library(broom)
library(gt)
library(performance)

# Load the example BFI data included with the psych package
data("bfi", package = "psych")

# Standard scoring keys supplied for the BFI data
bfi_keys <- list(
  Agreeableness = c("-A1", "A2", "A3", "A4", "A5"),
  Conscientiousness = c("C1", "C2", "C3", "-C4", "-C5"),
  Extraversion = c("-E1", "-E2", "E3", "E4", "E5"),
  Neuroticism = c("N1", "N2", "N3", "N4", "N5"),
  Openness = c("O1", "-O2", "O3", "O4", "-O5")
)

Methods

Data

We analyzed the bfi data set distributed with the psych package. The original data set contains 2800 participants and 28 variables. The first 25 variables contain personality items measuring five broad personality dimensions; the remaining variables contain demographic information.

The five personality dimensions were Agreeableness, Conscientiousness, Extraversion, Neuroticism, and Openness. Items were scored using the scoring keys supplied with the psych package, including reverse-scoring where required.

Show code 
#| label: prepare-data

# Score the five BFI scales.
# scoreItems() also provides scale reliability estimates.
bfi_scoring <- psych::scoreItems(
  keys = bfi_keys,
  items = bfi,
  min = 1,
  max = 6,
  impute = "none"
)

# Convert the generated scale scores to a tibble and retain demographics.
bfi_analysis <- bfi_scoring$scores |>
  as_tibble() |>
  bind_cols(
    bfi |>
      select(gender, education, age)
  ) |>
  mutate(
    gender = factor(
      gender,
      levels = c(1, 2),
      labels = c("Male", "Female")
    )
  )

Scale scores represent the mean of the available items belonging to each personality dimension. Missing item responses were not imputed; scale scores were instead calculated from the available keyed items.

Analysis

We first summarized the distributions of the five personality scores and examined their internal consistency using coefficient alpha. We then fitted two linear regression models predicting Extraversion

The first model included age and gender as predictors. The second model additionally included Neuroticism and Conscientiousness. The nested models were compared in terms of their R² and information criteria.

Before interpreting the retained model, we visually evaluated its regression assumptions using diagnostic plots produced by the performance package. These diagnostics were used to examine residual normality, linearity and constant residual variance, influential observations, and multicollinearity.
